# Concepts

This folder holds cross-unit concept notes.

## What belongs here

A concept goes here when it appears in **more than one unit** of your resource.
Do not create concept notes upfront — let them emerge while studying.

When you write something in a learning file and think "I'll see this again across chapters/lessons" — that's the signal to create a concept note here and link to it.

## Naming

Use lowercase slugs: `replication.md`, `consistency-models.md`, `event-driven.md`
Reference them from learning files with `[[concept-name]]`.

## Workflow

1. Write freely in `unit-XX-slug-learning.md` while studying
2. After finishing the unit, review your notes
3. Spot the ideas that feel cross-cutting
4. Create or update a note here using `_concept-template.md`
5. Add `[[concept-name]]` links back in the learning file

## Graph view signal

Concept notes connected to many unit learning files = core ideas of the resource.
These are worth a dedicated standalone article, beyond the per-unit output.
